## Context-aware networking (focused source update)

The cold-outreach guide now derives useful objectives from current goals, application stage and relationship evidence. It favors existing offers and commitments, researches up to three new contacts for a relevant gap, and uses the selected profile’s writing preferences. New recommendations include identity, relevance, a verified connection route, sources and a draft; routine updates report only meaningful changes. Existing person suggestions, application tags and company research remain the persistence model, without new schemas or schedulers. Human drafts and done/dismissed states are preserved.

This focused update describes source instructions, not measured agent quality or hosted deployment. Connected inbox access and actual execution still depend on the authorized agent runtime. The generated wiki’s broader source-revision limits remain unchanged.

Networking clarification: requested engineers trigger public-web discovery when existing contacts do not satisfy the request. Known interviewers get sourced professional research for preparation, not automatic outreach. Email body and To/CC details provide evidence, but copied recipients alone are not confirmed interviewers. Save confirmed and uncertain identities with message evidence in existing application-linked interview briefs. Cold drafts visibly use the saved style through a verified recipient-specific reason, a candidate achievement and one ask. No new record type or tool is added.
