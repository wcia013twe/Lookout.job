# Google sign-in asset

`google-g.png` is Google's official multicolor G, sourced from
https://developers.google.com/static/identity/images/g-logo.png.
Used only with Google sign-in text on a white button; no recoloring.
Brand guidance: https://developers.google.com/identity/branding-guidelines.

# Lookout assets

The Lookout SVG and PNGs derive from root icon.svg, using charcoal (#0e1116)
and lavender (#e9dcff). PNG sizes: 180px Apple touch, 192/512px app icons.
The 512px maskable variant uses a square background and safe-area artwork.
Regenerate PNGs with the installed Sharp package after changing the SVG master.
