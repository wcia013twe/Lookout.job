# Circles — conversations with context

Mode: Operate. Code-led composition inside the established Lookout visual system.

THESIS: Friends talk in a private Circle; an optional job, employer job ID, interview stage or offer comparison makes the same conversation useful later.
OWN-WORLD: Preserve the workspace typography, navy/lavender dark theme, existing light theme, Circle identity, companions and cloud cottage assets. No replacement brand or new token system.
STORY: Open Circle chat, browse a round insight with a compact shared application row, open its existing thread, or attach a shared job to a new private draft. Review before publishing. Offer comparisons participate in the same conversation stream.
FIRST VIEWPORT: Circle identity and controls; a compact collection/member rail; a prominent conversation column whose first example demonstrates job ID and stage; a supporting clubhouse invitation and shared job context. The composer follows the bounded conversation stream rather than obscuring its useful content.
FORM: Collections filter existing published threads rather than creating separate channels. Search stays server-backed. Shared jobs support accessible attach buttons and drag/drop. The sidebar collapses below the main content on smaller screens. Thread detail retains its existing reading layout, replies and review controls, with the same compact job attachment and offer details.

Scope: Main Circle overview, clubhouse activity, general chat and composer. Preserve the linked demo-interview-report thread page, membership, moderation, citations, exact-revision review and account boundaries. No messaging transport, notification, online presence or scheduled delivery claims. This is a conversation-oriented presentation of the existing permission-aware thread service, refreshed periodically.

States: General discussion, round insight, context-only legacy entry, offer comparison, shared resource, milestone, private draft, empty/filtered feed, search, declined publication, saved reply, withdrawn contribution. Fictional preview stays resettable and isolated.

### Clubhouse and activity follow-up

Left navigation is limited to Clubhouse, Company Intel and Resources. Clubhouse is
the default central view, with member companions, opt-in shared activity cards and
a shared update composer. Company Intel combines interview experiences, offers,
company context and milestones; Resources keeps the shared shelf. The right rail
is a freeform Circle chat and a simple message composer. On mobile, navigation
becomes three horizontal choices and chat follows the main view. Preserve existing
thread detail, private draft review, explicit publication, job attachments and offer
comparisons. Chat uses the existing periodic refresh and publication service.
Companion movement remains decorative. Activity displays only authored published
updates: three highlights, a weekly goal and an optional help request. No automatic
private tracker sharing, live presence or inferred submission counts.
Composer extension: User-pinned prompt-box reference. Keep the existing Circle layout and theme; compose naturally in a roomy rounded field with plus and review arrow. `@` or plus reveals searchable application/referral/Circle context; selected chips expand into explicit snapshots, reusing the compact application attachment. Drag/drop offers an equivalent attachment path. Additional post fields stay collapsed. Review saves privately before the separate sharing action. Desktop and mobile retain the same interaction hierarchy. No chat transport or agent fetching claim is introduced.
