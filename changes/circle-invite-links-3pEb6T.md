# Circle invite links

Circle owners can copy a private seven-day invite link. Opening it prefills the join form, including after sign-in, while leaving the name and join confirmation to the recipient. Revocation and expiration still apply. The fictional Circle preview supports the same flow.

Validation: full test suite and data validation; production frontend build; targeted Circle tests; browser check of fictional link creation and join prefill, plus signed-out invite preservation.

Limits: OAuth provider redirect and an authenticated real-account join were not exercised.
