# Circle sharing defaults

- Default Circle knowledge read and write permissions on for new writable agent connections; users can deselect them. Default new Circle memberships to resource and opportunity link sharing. Existing choices and rejoin reset remain unchanged.
- Demo Circle settings reflect the new membership defaults. Circle sharing controls remain human-only; existing scoped MCP tools use the same saved policies.
- Validation: focused Circle and connection tests; full npm test (1,491 passed), data validation, frontend typecheck and production build passed. Browser recording reached the app, but the demo settings preview timed out before settings could be verified.
- Limits: hosted deployment and existing accounts are not changed by this feature landing.
