# interview-tracking

Scheduled interview confirmation items no longer appear on the Action Board;
rounds stay editable in Applications → Interview. The Action Board remains for
explicit decisions and actions needing attention.

Validation: `npm run validate:data` passed. No test suite or hosted deployment
was run for this presentation-only filter.

Limits: This does not connect Lookout to an inbox or activate a background email
watcher. Muse email access depends on its separately authorized host connection.
