# action-board-sync

- The Action Board weekly planner now reloads its owned Supabase snapshot after matching account sync, focus and reconnect events. Existing-plan agent edits no longer require navigation; background refresh preserves unsaved budget input, keeps the agenda visible and blocks concurrent planner edits during reads.

- Added `docs/action-board-sync.md` with the storage/tool/scope mapping and a read-only hosted audit. Existing scoped tools cover board updates; approval and uncertain-submission resolution remain human handoffs. No new service/tool or gateway instruction contract was introduced.
- Validation: `npm run feature:doctor`; integrated `npm test` passed all 422 tests, including database scenarios; `npm run validate:data` passed for 76 roles; production `npm run build`, frontend typecheck and `git diff --check` passed. The initial sandbox test run failed three subprocess-based files; the complete rerun outside the sandbox passed. Complete output is retained in `/tmp/action-board-sync-tests.log`, `/tmp/action-board-sync-tests-unrestricted.log` and `/tmp/action-board-sync-tests-integrated.log`.
- Integrated concurrent local-main changes before landing, including the durable company workspace. Updated the mapping to `company_action` and `list_companies` / `list_company_workspaces` / `save_company_workspace`; hosted company tables/RPC are absent too.
