# Clean agent assignment choices

My Agent task pickers omit unselected revoked, expired and non-publishing connections. Already selected unavailable entries remain removable with a precise reason. Historical credentials and dependent records are retained; backend ownership/scopes and website/MCP schedule validation are unchanged.

Detached demo fixtures include retired and expired connections. Focused checks cover hidden backlog, selected stale entries, missing batch access, invalid expiry and reset isolation. Full npm test: 1,330 passed, 5 skipped, 0 failed. Frontend typecheck, production static export, 158-role catalog validation and diff checks pass. Desktop/mobile verification covers the picker and removal of a stale assignment without real account traffic.

Account maintenance: the three hosted tasks were reassigned from revoked Muse Local to the owner’s active Muse connection, with current-version fencing. No credentials were revived, permissions granted, records deleted or external messages sent. Local connections retain their separate local identity. Runtime scheduler registration and networking permission activation are not certified by these checks.
