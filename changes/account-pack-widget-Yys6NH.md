- Discover renders optional account-owned card pack widgets instead of a global hardcoded Zero2Sudo component. Each widget selects a My Agent task; tasks own instructions, sources, assigned connections and on-demand/requested recurring timing. Existing batches and canonical jobs hold cards and private analysis; no new tables.
- Added bounded, versioned settings and a narrow browser/MCP settings writer, with owner/timestamp checks and protection from stale autosync. Publishing checks the actual active connection and enabled task/widget, records task/publisher provenance, and reserves server-generated pack routing keys. Pausing/removing tasks stops new publications while retaining prior batches.
- UI supports task editing and source/connection assignments, widget create/edit/disable/remove, copied agent requests, private paginated feeds and explicit API errors. Historical Zero2Sudo data is an explicit dated archive opt-in. Guest and new account views have no inherited packs.
