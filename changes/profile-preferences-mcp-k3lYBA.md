Muse no longer needs to reconstruct the entire history for routine entry edits. - Exact profile timestamps fence entry positions and reject stale/repeated adds/removals. Other entries, unknown existing entry fields and unrelated profile facts remain intact. Changes invalidate verification; no-op updates preserve it. Updated agent instructions and incremented developerVersion.
