# circle-appearance

- Added one Customize modal: personal builtin/transparent PNG avatars, optional 4×3 idle/walk/celebrate sprite sheets, motion preview, save, owner-selected complete room theme, downloadable creator manifest and copyable AI prompt. Personal avatars follow their owner across Circles; room and activity-card identities use the selected artwork. Initial room choices are the existing cottage with two lighting palettes.
- Added private membership-scoped appearance reads and human-only revision/idempotency-checked writes. MCP uses the existing read/manage handoff rather than permitting agents to save a human's selection. Creator rooms remain reviewed data/local assets, not executable packs, a room editor or marketplace. No new dependencies.
- Updated the resettable fictional demo, migrated SQL tests, backend/OpenWiki documentation and agent guide (contract 165, Circle guide 3). Added a repeatable browser check that blocks account traffic and records the demo.
- Validation: full `npm test` passed 1,380 tests, including migrated database scenarios. Focused appearance/tool-surface checks passed 13 tests. Frontend and intelligence typechecks, data validation (158 roles), toolkit consistency and diff whitespace checks passed. Browser checks passed builtin/still/sheet saves, owner theme persistence, activity identity, creator download, invalid dimensions, mobile overflow, reduced motion and Escape. Recording: `/tmp/circle-appearance-demo.mp4` (local Playwright fallback after T3 preview timeouts).
- Limits: no hosted migration, deployment, authenticated hosted-browser test, push or PR. SQL validates PNG headers/geometry, while the browser validates decoded artwork/transparency. Inline private image data avoids public asset hosting but increases member-read payload sizes; people can retain images already received. Creator room geometry still requires manual whole-cycle review. Production availability requires the normal migration/frontend/gateway release flow.
- Production static build passed, including the downloadable template among 435 offline assets.
