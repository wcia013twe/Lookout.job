Anthropic's agent-eval guidance (https://www.anthropic.com/research/demystifying-evals-for-ai-agents) favors deterministic graders where possible and checking outcomes rather than prescribing incidental steps. These are product regression tests, not live model-reliability evals; no model grader, paid API or testing dependency was added.
- Removed 38 tests that inventoried exact demo contents, pinned guide prose or cosmetic preferences, or repeated centrally checked tool registration. Retained action-based demos, render behavior, all SQL scenarios, owner/scope/consent protections, stale versions, retries and submission uncertainty. Two stronger checks replace repeated setup/reset spot checks: whole demo graph independence and database row/session isolation with custom-history bypass.
- A small full-suite wrapper migrates current source once and writes a disposable PGlite snapshot; 35 ordinary fixture call sites can load independent instances. Explicit migration lists/directories/hooks still replay migrations. Direct focused Node runs retain their existing setup. Temporary data is removed after the runner exits; no persistent schema cache or extra dependency.
- The stronger demo check exposed shared nested preparation-resource topics. Both workspace fixture factories now clone their returned graphs so nested demo edits cannot leak into a later reset.
- A recent main-branch debrief-kind change left one consumer test querying notes. Updated it to query interview_debrief, retaining version/readback and private forum checks.
- Validation so far: snapshot/renderer smoke, independent database fixture, whole-graph demo isolation, debrief consumer tests, data validation (158 roles), diff/syntax checks and production static build passed. Initial full run: 996 passed, five skipped, one stale debrief test failed (subsequently corrected and passed). Final integrated full-suite validation follows below.
