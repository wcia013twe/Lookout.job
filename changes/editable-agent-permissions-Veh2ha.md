- Added an inline Edit permissions form to active connections under My Agent. Save/Cancel preserves unselected access, token, ID, name and expiry. Saved changes are read back before confirmation; account changes discard late responses. Revoked/expired connections remain uneditable.
- Added human-only connections.permissions through the existing authenticated gateway and service-only management RPC. Updates lock the owned active row, validate supported nonempty scope sets and reject stale expectedScopes. No token is generated, exposed or extended; existing issuance/revocation/profile setup paths are preserved.
